**How this page is kept**

- It is updated in the same pull request as the work that opens, changes or closes an item. Work that turns up a new follow-up adds it here before the PR merges.
- **Who:** _Owner_ means a decision, account, payment or approval only the owner can give. _Build_ means engineering work any agent can do once its inputs exist.
- **Status:** _Open_, _Blocked_ (says on what), _Deferred_ (owner decision, with date), or _Closed_. Closed items move to [Recently closed](#recently-closed) with the date and PR.
- IDs are stable; don't renumber. New items take the next free number in their stage.
